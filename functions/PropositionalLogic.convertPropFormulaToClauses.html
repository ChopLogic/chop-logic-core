    Function convertPropFormulaToClauses

    • convertPropFormulaToClauses(formula: PropFormula): PropClause[]

      Converts an arbitrary propositional formula to an equivalent set of clauses (the full clausal form conversion: Implications, Negations, Distribution, Operators).

      The formula is converted with convertPropFormulaToCNF, then nested conjunctions are flattened into a list of clauses and nested disjunctions into a list of literals:

      • φ1 ∨ ... ∨ φn → {φ1, ..., φn}
      • φ1 ∧ ... ∧ φn → {φ1}, ..., {φn}

      Since clauses are sets, duplicate literals within a clause and duplicate clauses (regardless of literal order) are removed; the first occurrence order is preserved. Tautological clauses such as {p, ¬p} are kept.

      A formula equivalent to a tautology yields no clauses ([]); a formula equivalent to a contradiction by constant folding yields the empty clause ([[]]). The input formula is not mutated.

      Parameters

      • formula: PropFormula

        The propositional formula to convert.

      Returns PropClause[]

      The list of clauses; each clause is a list of literals (p or ¬p).

      Throws

      If the formula contains an unknown operator.

      Example

      // ¬(g ∧ (r ⇒ f))  is converted to  [[¬g, r], [¬g, ¬f]]
      convertPropFormulaToClauses({
        operator: Operator.Not,
        values: [{ operator: Operator.And, values: [g, { operator: Operator.Implies, values: [r, f] }] }],
      });
