    Function isPropResolvent

    • isPropResolvent(
          clauses: PropClause[],
          resolvent: PropClause,
          resolvedLiteral?: PropFormula,
      ): boolean

      Checks whether a clause is a resolvent of two clauses by the Resolution Principle: for some complementary pair χ in one clause and ¬χ in the other, the resolvent equals the union of both clauses without that pair. Clauses are compared as sets of literals.

      If resolvedLiteral is given, only the complementary pair on that literal is considered. The resolved literal is the positive literal of the pair (χ, not ¬χ).

      Parameters

      • clauses: PropClause[]

        An array of exactly two parent clauses.

      • resolvent: PropClause

        The clause to check.

      • OptionalresolvedLiteral: PropFormula

        Optional positive literal the resolution must be performed on.

      Returns boolean

      True if resolvent is obtained by resolving the clauses (on resolvedLiteral, if given), otherwise false. Returns false if resolution is not applicable to the clauses.

      Example

      isPropResolvent([[p, q], [notQ, r]], [p, r]); // true
      isPropResolvent([[p, q], [notQ, r]], [p, r], q); // true
      isPropResolvent([[p, q], [notQ, r]], [p, r], p); // false
      isPropResolvent([[p, q], [notP, notQ]], []); // false, resolving on one pair leaves the other
