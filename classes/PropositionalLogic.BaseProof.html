    Class BaseProof<TStep>Abstract

    Abstract base class for proofs in every supported calculus.

    Holds the goal formula and the ordered list of proof steps, and provides the read-only accessors shared by all proof systems. Steps are always copied when stored and when returned, so callers never share state with the proof.

    Concrete proof systems (HilbertProof, NaturalProof, ResolutionProof) extend this class with methods for adding steps and define when a proof is complete.

    Example

    const proof: BaseProof<PropProofStep> = new HilbertProof(goal);
    proof.getStepCount(); // 0
    proof.isComplete();   // false
