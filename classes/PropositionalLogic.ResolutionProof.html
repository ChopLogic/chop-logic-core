    Class ResolutionProof

    Represents a resolution proof (Robinson-style refutation) of a goal formula.

    A resolution proof of a goal φ from premises Δ is a derivation of the empty clause {} from the clausal form of Δ ∪ {¬φ}. Premises are converted to clauses with convertPropFormulaToClauses; the clauses of the negated goal are added with ResolutionProof.addNegatedGoal; new clauses are derived with ResolutionProof.resolve.

    Example

    const proof = new ResolutionProof(r);
    proof.addPremise(p);         // 1. {p}
    proof.addPremise(pImpliesR); // 2. {¬p, r}
    proof.addNegatedGoal();      // 3. {¬r}
    proof.resolve(1, 2);         // 4. {r}
    proof.resolve(3, 4);         // 5. {}
    proof.isComplete();          // true

    replace

    • replace(atom: PropAtom, substitute: PropAtom): void

      Renames a variable throughout the proof: in the goal formula and in every clause. Literals that become equal are merged.

      The goal is renamed together with the clauses, so the negated goal steps always stay the negation of the goal. The renamed proof is then a proof of the renamed goal from the renamed premises.

      Merging literals can change which complementary pairs a clause contains, so after renaming every derived step is checked again. If a derived clause would no longer be a resolvent of the steps it was derived from, the replacement is rejected and the proof is left unchanged.

      Only atom-for-atom substitution is supported, since substituting a composite formula would break the clausal form.

      Parameters

      • atom: PropAtom

        The atomic proposition to replace

      • substitute: PropAtom

        The atomic proposition to substitute

      Returns void

      Throws

      if a derived step would no longer follow from its parent steps by resolution
